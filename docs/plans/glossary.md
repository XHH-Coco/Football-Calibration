# 术语人话对照表（全组口径）

> 状态：2026-11-20 · 由 M5 维护 · 权威来源 `docs/plans/08_小组分工实施方案_v1.3.md` §1
> 本表是全组统一的术语口径：报告、幻灯、图注、代码注释一律按此表述，不再出现「把 ECE 说成误差率」「把 log loss 说成损失函数值」这类歧义。
> 模型标识一律 `B0`–`B6` + `B6r`；`M1`–`M5` 只指成员。

| 术语 | 人话 | 为什么我们要它 |
|---|---|---|
| log loss（对数损失） | 你给真实结果的那个概率有多低，取对数后罚分。给 90% 却错了罚得很惨；给 34% 错了罚得轻。三个类别都算 | 我们的**主指标**，同时惩罚「不准」和「乱自信」，是严格 proper 的 |
| 准确率（accuracy） | 猜对的比例 | **不用它**。足球顶天 50% 出头，分辨不出模型好坏 |
| Brier score | 三个概率与实际结果的平方差之和 | 第二指标，跟 log loss 互为稳健性检验 |
| Murphy 分解 | 把 Brier 拆成三块：校准（reliability）、区分度（resolution）、难度（uncertainty） | 让我们能说「错在没校准」而不是笼统说「错」 |
| 校准（calibration） | 你说 30% 的事，长期看是不是真的发生了 30% | 本项目的核心概念 |
| ECE（期望校准误差） | 把预测按概率分箱，每箱「平均说的概率」与「实际发生频率」之差，按箱大小加权平均 | 一个数概括校准好坏 |
| 可靠性曲线 | 横轴＝模型说的概率，纵轴＝实际发生频率；完美校准就是对角线 | 最能一眼看懂的图 |
| 过度自信 / 欠自信 | 说 40% 结果只发生 30%＝过度自信；说 10% 结果发生了 18%＝欠自信 | 描述模型侧校准误差的形状（H1 的辅助证据） |
| 去抽水（de-vig） | 博彩赔率含抽水，三个隐含概率加起来约 1.05 而不是 1，要按某种规则压回 1 | 不压回 1，就没法跟我们的概率比 |
| rolling-origin | 用某季之前的所有比赛训练、预测该季；再往前滚一季，重复 8 次 | 唯一正确的时间序列验证，防止「用未来预测过去」 |
| 泄漏（leakage） | 训练时用到了预测时不可能知道的信息（如全场射门数去预测本场胜负） | 一旦泄漏，结果好得不真实，全部作废 |
| 簇 bootstrap | 有放回重抽 48 个「联赛-赛季」块，每次重算结论，看结论抖不抖 | 给每个结论配区间，而不是只报一个数 |
| 等价性检验 | 不是「没测出差异」，而是「差异小到可以当一样」（全项目统一 **±0.02 nats**） | C1/C2 与 H2 判据②都必须这么说，否则「没显著」什么都证明不了 |
| Dixon–Coles | 1997 年的进球模型：每队有进攻力、防守力，主队有主场加成；再加时间衰减与低比分修正 | B4 就是它，H2 的主模型 |
| ξ（xi） | 时间衰减速度，越大＝越只看近期 | B4 第一个待调参数 |
| ρ（rho） | 低比分相关性修正（足球里 0-0、1-1 比独立 Poisson 算出的更频繁） | B4 第二个待调参数 |
| Elo | 棋类积分，赢了加分、输了扣分，赢强队加得多 | B1 |
| 有序 logit | 承认「主胜 > 平 > 客胜」有顺序的回归 | B2 |
| 梯度提升（GBM） | 一堆小决策树，每棵纠正前一棵的错；本项目统一用 sklearn 内置 `HistGradientBoostingClassifier`，不装第三方 GBM 库 | B5a、B5b |
| 主场优势参数 γ | 主队进球期望的乘性加成，γ=0.2 ≈ 主队多进约 22% | **附录 A1** 的描述性序列，不占假设编号 |
| 空场期对照 | 2020–21 赛季几乎无观众 | **附录 A1** 的对照窗口；同期混杂多，只作描述，不称「自然实验」 |
| 校准斜率 | 估 `logit(真实结果) ~ a + b·logit(预测概率)` 的 b；b>1＝预测太保守（under-dispersed） | H1 核心统计量；**b>1 时低概率区曲线在对角线下方** |
| design effect | 簇内相关让 48 块有效样本量小于 16,733 场的程度 | 每个区间旁边都要报（W3） |
| 冷门–热门偏差（FLB） | 市场把冷门概率抬得太高、热门压得太低 | H1 的理论先验（Ali 1977；Cain et al. 2000） |
| B6r 重校准市场 | B6 过两参数 temperature-and-bias logit 映射；参数只在 train 段拟合 | H4 的唯一工具（提交版叫 `MK*`） |

## 补充（M5 分析常用）

| 术语 | 人话 |
|---|---|
| 偏差（bias） | 预测概率减实际频率；正＝说高了 |
| 局部平滑 / 核回归 | 用滑动窗（或核）估局部频率，曲线更接近真实形状（W7） |
| 样条 / GAM | 分段多项式拼成光滑曲线（W5） |
| 严格 proper 评分规则 | 只有「说真话」才拿最低分的规则；log loss / Brier / RPS 都是 |

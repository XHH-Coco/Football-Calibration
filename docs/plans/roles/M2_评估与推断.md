## 1. 你这个岗位在做什么（人话）

**你是裁判兼书记员。**

九个 arm 交上来的东西长得一模一样：三列数字，每行一场比赛。**只有你能判分。** 而且必须是同一套尺子——如果有人自己写了个评估脚本，算出"我们的模型赢了市场"，这个数不能进报告，因为没人知道他扣分扣得对不对。

你还有一半活是"书记员"：报告里每一个 `Δ = 0.013`，后面都得跟一个括号 `（90% CI: 0.004 – 0.022）`。**这些区间是你算的，也是全项目最能让老师点头的地方**——它证明你知道"48 个样本"和"一万七千场比赛"根本不是一回事。

为什么这件事重要？因为足球预测里最容易出现的假发现，就是**把 16,733 场比赛当成 16,733 个独立样本**。这样算出来的区间会窄 3–5 倍，于是任何一点噪声都会变成"显著提升"。你这关守住了，整份报告才站得住；守不住，后面所有结论都是假的，而且是**看起来最漂亮的那种假**。

### T2.5 三种去抽水，各自在做什么（人话）

| 方法 | 一句话 | 什么时候会不一样 |
|---|---|---|
| 比例法 | 把三个隐含概率按比例压回 1（最常用、最粗暴） | 热门场次会被低估一点 |
| power 法 | 找一个指数 k，让 `Σ p_i^k = 1`（相当于认为抽水是乘性的） | 冷门场次与比例法差得多 |
| Shin 法 | 假设有一部分钱是"内幕交易"，把它的影响剥掉 | 三者中最"理论正确"，但依赖假设 |

**为什么必须三种都做**：如果只有一种，审稿人会说"你的结论是去抽水方法选出来的"。三种同号同量级，才是"不是 artifact"的证据。

## 7. 六个坑

1. **按"比赛"重采样**。这是本项目最容易犯、也最难被发现的错。48 个块才是独立单位，按 16,733 场重采样会把区间压窄 3–5 倍，然后你会"发现"一堆显著差异——**而且数字看起来非常漂亮**。写完先打印两种方法的区间宽度对比。
2. **不同模型没预测同一批比赛**。配对差要求逐场相减，如果 B4 少预测了 5 场（恰好是三列赔率缺失那 5 场），配对就对不上。**用 `match_id` 内连接后再算**（定义与 ISO 日期格式见 `data_interface.md` §1.0），并在表注写实际参与配对的行数。
3. **类别顺序反了**。`FTR` 是字符串 `H/D/A`，要映射成 `0/1/2`，且 `p_home` 必须在第一列。反过来不会报错，只会让 log loss 悄悄变差。
4. **去抽水时把赔率 ≤ 1 的脏数据带进去**。先过滤 `o_i > 1`，否则比例法会算出负概率。
5. **"看完全层结果再回去改内层网格"**。这就是用 test 调参，C1 与 H2 一起失效；**B6r 的两个参数同理只能吃 train**。内层网格必须在外层跑之前定死。 此外 B6r 只能用 train 段里 `PSCH/PSCD/PSCA` 三列齐全的比赛拟合（收盘赔率自 2012/13 才有，训练史前 9 季没有），每折拟合样本数 `n_fit` 写进日志；否则各折拟合口径不统一，H4 的分子分母不可比。
6. **把"区间太宽"写成"没有差异"**。区间比 0.04 还宽时，正确写法是"分辨率不足，不做判定"，不是"二者等价"。这一条老师一眼就能看出来。

## 8. 你需要的术语

| 术语 | 人话 |
|---|---|
| log loss | 你给真实结果的那个概率有多低，取对数后罚分。给 90% 却错了罚得惨，给 34% 错了罚得轻 |
| proper scoring rule | "诚实"的评分规则：只有报你真心的概率才能拿最高分。log loss 和 Brier 都是；准确率不是 |
| Brier | 三个概率与实际结果的平方差之和。与 log loss 互为稳健性检验 |
| Murphy 分解 | 把 Brier 拆成三块：校准好不好（reliability）、有没有区分度（resolution）、比赛本身多难猜（uncertainty） |
| 簇 bootstrap | 有放回地重抽 48 个"联赛-赛季"块，每次重算结论，看结论抖不抖 |
| 去抽水（de-vig） | 赔率隐含的三个概率加起来是 1.05 而非 1，要按某种规则压回 1 |
| 等价性检验（TOST） | 不是"没测出差异"，而是"差异小到可以当一样"。全项目唯一边界 0.02 |
| 校准斜率 | `logit(真实) ~ a + b·logit(预测)` 的 b；b>1 表示预测太保守，**低概率区曲线在对角线下方** |
| design effect | 簇内相关使 48 块的有效样本量缩水多少；每个区间旁都要报 |
| B6r | 市场 B6 的两参数重校准版本，H4 的工具；参数只在 train 段**且 PSCH 三列齐全**的比赛上拟合 |
| cluster-robust SE | 承认块内比赛相关、块间独立的稳健标准误，用来交叉核对 bootstrap |

## 9. 卡住了怎么办

| 卡点 | 先做什么 | 找谁 |
|---|---|---|
| 某模型跑完 log loss < 0.95 | **先怀疑泄漏**，不要先优化：查该模型特征里有没有射门、赔率、当季统计 | M4（特征）、M1（切分） |
| 区间宽度看起来"太好了" | 打印重采样单位用的是块还是场 | 自查 |
| 配对差算出来行数不对 | 打印各模型 `match_id` 集合的差集 | M1（`match_id` 生成规则） |
| 三种去抽水结论不一致 | 先看是不是某几场赔率异常（差 > 0.05），逐场打印 | M5（他会拿来写结论） |
| M3/M4 说 `inner_split` 不好用 | 直接改接口，不要让他们各自写循环 | — |

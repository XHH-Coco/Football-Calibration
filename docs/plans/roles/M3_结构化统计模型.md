## 1. 你这个岗位在做什么（人话）

**你是造主炮的人。**

**H2、H3、H4 三条主推断都挂在 B4 上**（它只用赛前比分信息）。B4 是那个"老老实实写进球机制"的统计模型：它假设每场比赛是两个 Poisson 过程——主队按一个速率进球、客队按另一个速率进球，然后从这两个速率算出 0-0、1-0、2-1 等所有比分的概率，再加起来得到主胜/平/客胜。

**你的模型如果收敛不了，或者 ξ 每次都跑到网格边界上，这三条都没法算，项目的核心贡献就塌了。** 所以你的任务被刻意提前到第二周开工，而且方案里给你留了兜底（T3.8）——这不是不信任你，是因为这是全项目唯一的单点故障。

好消息：这门课的方法你其实都学过。B3/B4 本质就是**带约束的极大似然 + 加权**：
- 极大似然 = 找一个参数组合，让"实际发生的比分"出现的概率最大；
- 加权 = 越久远的比赛权重越低（`w = exp(−ξ·天数)`）；
- 约束 = 让所有队的进攻力加起来为 0，否则解不唯一。

你还有第二个任务：**附录 A1（γ 的长期轨迹）**。v1.3 把原来的 H3 主场优势假设**降为描述性稳健性分析**：22 点逐季序列、样条趋势、空场期对照都保留，但**不做因果主张**——只有一个空场季，同期还有赛季腰斩、赛程压缩、换人规则变化。样条 / 局部平滑在主线里由 M2 用于 H1 可靠性曲线与 H3 轮次 sweep。

## 3. 第一天 30 分钟：先让 α 排对序

不用管 48 折，先只拟合**英超 2010/11 一个赛季**的 B3（不带 ξ、不带 ρ）：

1. 读该季 380 场；
2. 每队两个参数（进攻力 α、防守力 β），全局基线 μ，主场加成 γ；
3. `scipy.optimize.minimize(method='L-BFGS-B')` 最小化负对数似然；
4. 把 20 支队的 α 排序打印出来。

**判据**：曼联、切尔西、阿森纳在前，桑德兰、维冈在后 → 似然写对了。
**如果排序是乱的**，八成是主客场的正负号搞反了：主队进球率里应该是 `+α_home − β_away + γ`，客队是 `+α_away − β_home`。

> **这一步比任何单元测试都快。** 因为你能立刻用"谁强谁弱"的常识去验，而单元测试只能验"代码没崩"。

### ξ 与半衰期的换算（可以直接用，不用再推）

| ξ | 半衰期 | 人话 |
|---|---|---|
| 0.0005 | 3.8 年 | 十年前的数据还有 1/4 的权重 |
| 0.0010 | 1.9 年 | |
| 0.0019 | 1.0 年 | 一年前的比赛权重减半 |
| 0.0030 | 0.63 年 | |
| 0.0050 | 0.38 年 | |
| 0.0080 | 0.24 年 | 基本只看最近十几场 |

> 半衰期 = `ln2 / ξ / 365`（年）。**这张表已经核算过，不要改。**

### τ 函数在做什么（人话）

独立 Poisson 会低估 0-0 和 1-1 的概率——真实足球里低比分比"两个独立过程"算出来的更常见。τ 就是给这四个格子（0-0、1-0、0-1、1-1）单独乘一个修正系数，系数由 ρ 控制。**它只改这四个格子，其他比分不动**，所以对主胜/平/客胜的影响是间接的（通过归一化）。

## 7. 五个坑

1. **参数不可识别**。不约束 `Σα = 0`，α 和 β 会一起漂移，优化器会"收敛"到一个任意解，而且看起来很正常。
2. **warm start 是必须的，不是优化**。48 折 × 1,440 次冷启动在这个时间窗里跑不完。用上一折的解做初值。
3. **升班马没有历史**。每季每个联赛必有 3 支新队，它们在训练集里不存在。用"联赛新队平均值"初始化 + 轻微 L2 收缩，别让它把似然带崩。
4. **不要用目标赛季的任何信息选 ξ/ρ**，包括"看一眼哪个 ξ 让 2024/25 更漂亮"。这是 C1 与 H2–H4 全部成立的前提，也是老师最会问的一句。
5. **A1-a 别用 8 个折点讲二十年**。fold 的 γ 是"截至该季的累计窗口"估出来的后验量，横轴语义不对，而且 8 个点看不出趋势。要用 22 点逐季序列。

## 8. 你需要的术语

| 术语 | 人话 |
|---|---|
| 极大似然 | 找一组参数，让"实际发生的事"出现的概率最大 |
| Poisson 分布 | 描述"一段时间内发生 k 次"的概率。用它建模"一场比赛进 k 个球" |
| 加权似然 | 每条观测乘一个权重再求和。老比赛权重低 = 更看重近期 |
| 半衰期 | 权重掉到一半所需的时间 |
| Dixon–Coles | 1997 年的进球模型：进攻力、防守力、主场加成，再加时间衰减和低比分修正 |
| 主场优势 γ | 主队进球期望的乘性加成。γ=0.2 ⇒ 主队多进约 22%（`exp(0.2)−1`） |
| 空场期对照 | 2020–21 几乎没观众；**只作描述性对照**，同期混杂多，不称自然实验 |
| 样条 / GAM | 用分段多项式拟合一条光滑曲线，比折线更能看出趋势（第 5 讲） |
